## 1️⃣ TrendEra – Smart E-Commerce Application

### 🔍 Overview

**TrendEra** is a modern e-commerce mobile application built using Flutter. It delivers a seamless shopping experience enhanced with AI-powered image search and secure authentication.

### ✨ Key Features

* Complete e-commerce shopping flow
* **Google OAuth Authentication**
* **Role-based access** for Admin and Users
* AI-powered image search using **Gemini API**
* Efficient and scalable state management with **Riverpod**
* Clean MVP architecture

### 🛠 Tech Stack

* Flutter
* Riverpod
* Firebase Authentication
* Gemini API
* Cloudinary (Image Storage)

## 4️⃣ Logo Studio – Logo Creation & Authenticity Verification Platform

### 🔍 Overview

**Logo Studio** is a web-based application that allows users to design logos using a Canva-like editor and verify logo authenticity using pixel-based analysis.

### ✨ Key Features

* Canva-style logo editor
* Fake vs original logo detection
* **Pixel Matching Algorithm** with classification score
* Logo download and history tracking
* User analytics and interaction tracking
* Dedicated **Admin Dashboard** for logs and usage insights

### 🛠 Tech Stack

* Flutter Web
* Firebase Authentication
* Cloudinary (Image Storage)
* Custom Image Processing Algorithms
