## 🚀 Overview
[cite_start]**C-Cube** is an intelligent career guidance platform designed to bridge the gap between academic learning and professional readiness[cite: 8, 9]. [cite_start]It utilizes a domain-specific logic to provide students with tailored milestones for their career growth[cite: 9].

## ✨ Key Features
* [cite_start]**Domain-Locked Networking**: Users can only login via their college email[cite: 9].
* [cite_start]**Automatic Sorting**: The app auto-fetches the email domain and adds the student to their specific college database[cite: 9].
* [cite_start]**Milestone-Based Guidance**: Provides smart recommendations for courses, internships, and projects with milestone tracking[cite: 9].
* [cite_start]**Leaderboard Dashboards**: Features college-level leaderboards using milestone points to drive interactivity[cite: 9].
* [cite_start]**Secure Auth**: Integrated with **Google OAuth Login** for secure access[cite: 9].
